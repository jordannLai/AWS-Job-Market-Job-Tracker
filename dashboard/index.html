How this works

  • Every morning, EventBridge Scheduler triggers a Python Lambda function that pulls the newest postings for each role from the Adzuna API into an S3 data lake. A second function flattens the data and tags each posting with the skills it mentions, and a third publishes the numbers on this page.
  • Skill shares count each posting once, even when it appears on several days. The cloud platform trend instead shows each day's sample of current postings.
  • Adzuna returns only part of each job description, so these percentages undercount real demand. Compare roles and trends rather than reading the numbers as absolute.
  • Salaries include only pay the employer stated. Adzuna's estimated salaries are left out.
